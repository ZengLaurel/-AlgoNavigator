# src/content/modules/array.test.ts

## Scenarios covered

- Six valid observation operations and six prediction questions, same trusted initial state as the Python harness.
- Array Python evidence: insert X at 1, replace original C with D, remove B gives A/X/D. Correct values without evidence or identities cannot pass.
- Camp Packing: grow to 5, insert map at 1, remove food at 2, traverse yields rope/map/lamp. Missing observation or fabricated history cannot pass.
- All four activities: demo must pass, wrong reason blocks, corrected rule opens a fresh reset example, fresh correct evidence learns.
- All four activities: hints cap at three without awarding mastery; incorrect outcomes cannot pass; reset/replay clear the appropriate attempt.

## Why this test exists

Array completion and teaching must follow actual structure operations rather than hard-coded success, final-value coincidences or chat claims.

## Known gaps

Pure content tests do not validate animation appearance, real-model wording or a child learning outcome. Browser checks and real Pyodide integration are recorded separately.

## Status

Actual per-case pass/fail, duration and input-linked names are generated by `npm run test:report` in [TEST-RESULTS.md](../TEST-RESULTS.md). Final counts are recorded in ARRAY-ACCEPTANCE.md.
