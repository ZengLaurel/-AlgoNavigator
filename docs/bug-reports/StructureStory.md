# src/components/game/StructureStory.test.tsx

## Scenarios covered

Twelve cases cover array insertion/removal/growth, fixed linked-node identities and changed next/head references, detached visits, safe insertion order, FIFO departure, peek without removal, newcomer arrival, rejected empty operations, independent playback and matching events in program replay.

## Why this test exists

An attractive animation must not teach the wrong data-structure rule or mutate grading evidence. Boxes and boats keep identities; place labels stay fixed; stones stay put when ropes change. Before/intermediate/final scenes are explanatory previews, not new application actions or mastery evidence.

## Latest results

2026-11-12: 12/12 new tests pass, full 352/352. [Case-by-case inputs, expected behavior, actual status and timings](../STORY-ANIMATION-TEST-CASES.md). [Browser evidence](../STORY-ANIMATION-ACCEPTANCE.md).

## Known gaps

Most deterministic cases mock reduced motion; a timer test covers automatic playback. They do not measure child comprehension, real OS motion preferences, all physical devices or final art sign-off. Browser appearance is checked separately; no frame-by-frame pixel comparison is claimed.
