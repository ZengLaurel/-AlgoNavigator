# src/engine/pyodide/moduleExecution.test.ts

## Scenarios covered

Real local Pyodide runs array insert/set/remove/traverse to A/X/D, chain insertion/head removal to x/b, and queue FIFO to B/C. Independent TypeScript replay checks each Python operation. Exception followed by a new run cannot retain previous_secret; replaced or directly tampered objects fail evidence. Catching invalid index and retrying is allowed; mismatched fixture is rejected. Output is bounded/labelled and 129 actions fail EVIDENCE_LIMIT.

## Why this test exists

Phase 11 introduces shared multi-module contracts. These regressions prevent cross-module state leakage, false success, data loss or unsafe reply rendering. Inputs and expected behavior are listed above and in the test source.
