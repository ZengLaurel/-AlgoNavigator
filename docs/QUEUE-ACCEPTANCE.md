## Limits and next work

Core browser flow and four teaching transfers were completed before asking AI anything, proving chat is optional. Tests also cover empty peek/dequeue, singleton behavior, duplicate-valued identities, forged/missing evidence, wrong event order, explanation gates, reset/replay and Python cancellation. Optional explanation prose is not automatically graded or persisted. All AI role samples are connectivity/content spot checks, not comprehensive dialogue-quality validation. The Tutor sample remained broad; more precise hint selection belongs in Phase 15 review.

Full keyboard-only journeys, physical narrow-screen devices, actual OS reduced-motion settings, broad browser combinations, school hardware cold starts and student learning outcomes were not measured here. Component tests exercise reduced motion; CSS and motion components respect it. Worker timeout/retry infrastructure retains earlier tests; this session did not repeat every lifecycle failure in every room. These remain explicit Phase 8/15/9 gates. The output collector’s concatenated print lines are an existing display limitation; operation returns and state are independently available in the event replay.

Next: Phase 15 joint acceptance across four modules, including navigation/storage isolation, failure recovery, accessibility/device checks and real-model guidance review. Four open regions do not mean every pilot gate has passed.
